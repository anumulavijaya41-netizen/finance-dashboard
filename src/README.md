# 📊 Finance Dashboard UI

## 🚀 Overview
This project is a clean and interactive Finance Dashboard built using React.js.  
It allows users to track financial data, view transactions, and gain insights into spending patterns.

---

## ✨ Features

- 📌 Dashboard Summary (Balance, Income, Expenses)
- 📈 Time-based visualization (Balance Trend)
- 🥧 Category-based visualization (Spending Breakdown)
- 📋 Transactions List (Date, Amount, Category, Type)
- 🔍 Search & Filter functionality
- 🔄 Role-based UI (Admin & Viewer)
- 💡 Insights Section (Top category, monthly comparison)
- 📱 Responsive Design

---

## 🛠 Tech Stack

- React.js
- JavaScript
- CSS
- Recharts (for graphs)
